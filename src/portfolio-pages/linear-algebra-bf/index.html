Linear Algebra BF

Your linear algebra best friend: a command-line program that stores matrices and row-reduces, inverts, exports and imports them, so the arithmetic is done for you.

Ax = b  ⇒  [ A | b ]  →  rref  →  x
  • C++
  • Command line

1Say hello

The program greets you with “Welcome to your Linear Algebra best friend!” and a prompt. Type options and it lists every command: add, remove, edit, reduce, invert, print all, export, import and quit.

← No menus, just commands.

2Enter a matrix

Type add, answer how many rows and columns, then feed it the entries one by one. Here a 3 × 4 matrix goes in:

A = 126368954567

← rows first, then columns

3See them all

Add as many matrices as you like, of any size, and print all numbers them from 0 so you can refer to each one.

← numbered from 0, like a good programmer

4Reduce and invert

Pick a matrix and reduce returns its reduced echelon form. invert hands back the inverse. These are the results from the screenshot:

rref(A) = 10012.333010−11.0000012.111
B = 3257
B−1 = 0.636−0.182−0.4550.273

← row operations, no pencil required

5Export

Done with a matrix? export saves it to a text file. You name it and .txt is added by default.

← saved as .txt

6Import

Bring matrices back in with import. Give it a file name (again, .txt is added for you) and the matrix joins the list. Two imports later, print all shows the new ones alongside the originals.

← the list keeps growing

Therefore, matrices are easier with a best friend. ∎
