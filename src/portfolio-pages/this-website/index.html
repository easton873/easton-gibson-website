What it is

My personal site and portfolio. It is built with Eleventy and Nunjucks templates, with plain CSS and a little JavaScript, and no frameworks.

The About page is scroll-driven, with clip-path reveal transitions and parallax. Several portfolio entries are one-off hand-built pages with their own look.

Every push to main builds the site and deploys it to GitHub Pages with GitHub Actions.
