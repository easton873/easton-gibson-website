0x00 // BOOT

COMMAND LINE
SMARTBUDGET

A budgeting program that lives in the terminal. No windows, no buttons: you type a command and it answers. Scroll to follow its timeline.

C++CLI

0x01 // FIRST RUN

Launch it in a new month and it notices, tells you there's no budget yet, and creates one before dropping you at the prompt.

0x02 // THE MENU

Everything is a typed command: report, stats, view, view all, save, open, constants, options and quit. Reporting adds its own: new, add, remove, reset.

0x03 // STATS

Type stats for the month at a glance: money to spend, already spent, still remaining, then every category's allotted, spent and remaining amounts.

0x04 // PLAIN TEXT

Budgets save as simple text files: a day number, how many purchases, then each purchase's category (#), description (@) and cost.

0x05 // THE SOURCE

Written in C++. Classes like Expenditure and BudgetDay hold the data, with methods to print and save each purchase.

0x06 // EXIT

> quit
